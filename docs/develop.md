### 🔍 Качество кода и статический анализ (ruff/mypy)

Перед каждым коммитом в Git разработчик обязан проверить свой код на соответствие стандартам проекта (PEP 8, аннотации типов, отсутствие скрытых багов). Все утилиты настроены в `pyproject.toml` и запускаются через менеджер `uv`.

#### 1. Линтер и автоформатирование (Ruff)
Ruff используется для мгновенной проверки кода и его автоматического форматирования.
```bash
# Проверить код на ошибки и соответствие стилю
uv run ruff check .

# Автоматически исправить безопасные замечания linter'а
uv run ruff check . --fix

# Отформатировать код по стандартам проекта
uv run ruff format .
```

#### 2. Проверка строгой типизации (Mypy)
Mypy проверяет корректность использования Python Type Hints.
```bash
# Полная проверка типов во всем проекте (flow/app и tasks/app)
uv run mypy

# Точечная проверка только для сервиса Flow
uv run mypy flow/app

# Точечная проверка только для сервиса Tasks
uv run mypy tasks/app
```

> 💡 **Быстрая команда разработки:** Для одновременного форматирования и исправления стиля одной строчкой используйте связку:
> `uv run ruff format . && uv run ruff check . --fix`
